# Examination Findings visual language

Source: uploaded prototype and handover Part 4. Read docs/AGENTS.md before consumption.

- Navy background with golden-brown accent family; light is a derived counterpart, not a different product.
- Inter UI, JetBrains Mono IDs/values, Georgia letter text.
- Cards use 12–16px corners, buttons 10px, sheets 20px top corners.
- Preserve gold gradient on primary hover; never replace it with grey.
- Semantic colours are reserved for severity and outcome, always with text.
- Glass blur is 18px at 140% saturation; no decorative animation obstructing evidence.
- Visible gold keyboard focus; 4.5:1 text contrast; reduced-motion support.
- Desktop app target: 58px header with internal scrolling. Below 900px, stack content without horizontal overflow.
- AI proposes; humans decide. Missing evidence is not a negative grade.
- Synthetic material must be labelled. Do not imply official CBUAE endorsement.

The pilot ships five families only. Read docs/references/component-inventory.md before adding any pending family. Do not migrate the existing app before the required families are implemented and visual approval is received.
